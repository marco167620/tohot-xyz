---
description: 將指定 Google Doc 轉換為部落格 Markdown 筆記
---

您可以透過以下指令，讓我自動執行轉換任務：

「請幫我讀取這個 Google Doc：[貼上連結]，並將其轉換為 Markdown 筆記。
1. 儲存於 `src/data/blog/notes/` 資料夾。
2. 檔案名稱請參考內容或標題，使用英文小寫與連字號。
3. Frontmatter 請參考現有筆記格式（包含 author: 馬可博士、pubDatetime、tags、description 等）。
4. 如果檔案已存在，請更新其內容。」

或者，您可以直接輸入簡短指令：
`/gdoc-to-note [Google Doc 連結]`

(註：若您需要我學習特定的 `/` 指令，我可以為您建立一個系統級的 Workflow 文件。)
