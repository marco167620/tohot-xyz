上一篇「觀察」文章探討了在 AI 與 Vibe Coding 的浪潮下，網站建置如何擺脫傳統 CMS 的臃腫與資安風險，走向「靜態分散式」與「無伺服器 (Serverless)」的現代化架構。接下來我與各位分享這個哲學的具體落實，曾陪伴我二十多年的專屬網域 tohot.net，已在全新的架構下正式重生。現在他已遷移至 Firebase 與 Cloudflare 等分散式服務，更有趣的是，我在這個極簡的靜態入口中，成功部署了一位 24 小時運作的「馬可博士 AI 數位分身」。我的 AI 團隊透過「數位治理」的思維，在零伺服器維護成本、確保極致資安的前提下，優雅地實現這一切。

![從架構解耦到數位分身：tohot.net 重生的實踐](/images/from-architectural-decoupling-to-digital-twin.png)

## 一、 資安治理：從邊緣運算落實「架構解耦」

在過去的 WordPress 時代，豐富的外掛生態往往是資安漏洞的溫床。如今我們轉向靜態網頁，杜絕了資料庫被攻擊的風險。當我們要為靜態網頁引入 AI 服務 (如 Gemini API) 時，我們徹底貫徹了「架構解耦」的理念。利用 Cloudflare Workers 建立了一個邊緣運算中繼站 (Proxy)，將 API 金鑰加密鎖在伺服器端的環境變數中。訪客的瀏覽器只與這個 Proxy 溝通，由 Proxy 代理向 Google 發出請求。

這意味著，我們在不租用任何傳統後端主機的情況下，建立了一道堅不可摧的防火牆，徹底保障了數位資產的安全。

## 二、 資源控管：以「苛刻介面」優化資源利用限制

在零成本的 Serverless 架構下，最珍貴的是 API 的呼叫配額。為了防止資源被揮霍，我們在介面設計上實施了兩項「數位邊界」：

*   **強烈冷卻：** 每次發話後，系統按鈕會進入 3 秒鐘的處理鎖定。這不僅是防範惡意腳本連發的盾牌，也讓對話節奏更從容。
*   **輪次配額：** 單一訪客的對話上限設為 8 次，確保有限的運算資源能公平服務更多人；若需深入探討，則自然引導至其他連絡方式，例如電子郵件。

這些看似微小的介面限制，實際上是資源分配的最佳化，讓我們得以在零成本的基礎上，維持系統的高效與穩定。同時，實務上的聯繫才是線上互動的目的，他應具有帶來商務的潛力。

## 三、 靈魂注入：精確定義的 AI 代理人

當 AI 成為程式碼與內容的加速器，我們更需要賦予它明確的邊界。為了讓這個數位分身真正代表「馬可博士數位治理實驗室」，我們透過嚴密的系統提示 (System Prompt) 建立核心邏輯。我們不僅賦予 AI 分身探討 Web3 與 ESG 的專業視角，更嚴格規定「回覆總字數不超過 300 字」，確保對話精準、犀利、不流於空談。此外，程式碼會動態注入當下的真實時間 (CST, UTC+8)，讓每一則回覆都具備時空的錨點。

## 結語：意義的展現，大於技術的展示

tohot.net 的重生，是前文所提「去中心化極簡網站革命」的一塊重要拼圖。它證明了，在 AI 高速發展的時代，建立一個具備互動能力、高效能且極度安全的網站，不再需要龐大臃腫的基礎設施。透過 Serverless 架構與精確的治理邏輯，我們能將精力 100% 投入到創意的發想與內容的產出上。

## 後記：以下是 AI 機器人的開發完成狀態

目前「馬可博士 AI 機器人」第一版已開發完畢並在 tohot.net 正式上線，進入穩定運行階段。
以下是目前的技術實施總結：

1.  **核心 AI 效能與安全性**
    *   **AI 模型**：使用 Gemini 2.5 Flash (v1beta 頻道)，兼顧回應速度與最新知識。
    *   **安全性 (Security)**：
        *   **金鑰隱蔽**：API Key 完全儲存在 Cloudflare Worker 伺服器端，前端程式碼 100% 零洩漏。
        *   **網域鎖定 (Strict Origin)**：目前已實施最高安全等級，僅接受來自指定網域的請求，徹底防止他人盜用配額。

2.  **UI/UX 與對話控制**
    *   **互動邏輯**：導入了 3 秒按鈕鎖定 (Cool-down) 與 8 輪對話限制，對話次數會跨頁面重整持續累積，直到隔日重置，兼顧體驗與成本控制。
    *   **即時感**：AI 回應包含當下的精確時間 (CST)，強化對話的真實感。

3.  **日誌與社交整合**
    *   **系統透明度**：前端控制台會即時顯示 API 溝通狀態，方便進階使用者與開發團隊監測。
